PROJECT PACKAGE STATUS

Included:
- Existing Python/Streamlit application and page modules
- Traditional image enhancement and segmentation code
- U-Net and CNN-Transformer model implementations
- Training and evaluation modules
- Official NLM dataset downloader
- Dataset preparation script
- Updated setup and dataset instructions

Not included:
- Original Montgomery dataset image and mask files (download separately)
- Trained model checkpoint files (must be generated by training)
- Real experiment results (must be generated by evaluation)

This package is therefore a completed source-code/setup bundle, not a pre-trained,
ready-to-demonstrate medical AI model. Train the models before using deep-learning
inference in the application.
